## 從 0.1.23 升級

照 [快速上手](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.md) 的「升級」一節升級 extension 與兩個 chart。subagent 預設開啟；用本機模型伺服器時，它要能同時處理兩個請求才會變快（Ollama：`OLLAMA_NUM_PARALLEL` 至少 2），不行的話設 `ai.subagents: false` 回到原本的單次呼叫。

## 新功能：分工 AI（subagent）

- 確認計畫後，網頁（`index.html`、`app.js`、`style.css`）和 API（`handler.py`）由兩個 subagent **同時**撰寫，不再由一次 AI 呼叫寫完四個檔。兩邊看不到彼此的程式，雙方的約定是計畫裡的 API 端點清單。
- 總覽頁「確認並部署」之後、以及詳細頁意見收斂在「AI 正在修改程式」時，頁面顯示兩張 subagent 卡片：各自負責的檔案、狀態、花的秒數與 token。
- 只改網頁的意見收斂，只派網頁 subagent，`handler.py` 維持原樣；範圍包含 API 時兩邊都重寫（API 一改，網頁讀的回應格式也可能變）。
- 寫完後比對網頁呼叫的 API 和計畫是否一致，有出入時在卡片下方提醒（只是文字比對，可能誤判，不擋發布）。
- 任何一個 subagent 失敗，整次都不發布，可以再確認一次。四個檔的檢查和以前完全相同。
- 新設定：chart 的 `ai.subagents`（環境變數 `LAOBAN_AI_SUBAGENTS`），預設 `true`。總覽頁的設定區顯示目前的模式。

## 介面語言

- 英文介面：意見收斂的動詞改用 consolidate（和英文 README 一致，不再用 converge）；紀錄裡的事件一律小寫開頭。
- 日文介面：用語和日文 README 一致——取りまとめ（原本是収束）、バージョン（原本「版」「バージョン」混用）、アーキテクチャ図（原本和「構成図」混用）、異議あり（原本是「意見あり」）、試食版（M0）；補完原本被截短的差異說明。
- 繁中介面：「打開」改「開啟」；「有意見」改「有異議」（原本和「提意見」容易混淆）；「程式庫」改「儲存庫」；狀態訊息的寫法統一。
- 括號、冒號、頓號不再寫死在畫面上：英文顯示 `Steps (3)`、`a, b`，中文與日文顯示「步驟（3）」「甲、乙」。
- 後端回的錯誤代碼，現在全部由頁面用介面語言說明，不會因為後端安裝成另一種語言（`config.language`）就看到另一種語言的訊息；檔案檢查之類帶有具體原因的錯誤，會在說明後面附上後端的原文。
- 測試會檢查三種語言的鍵是否一致、每個錯誤代碼都有翻譯、約定的用語，以及畫面上沒有寫死的標點。

Code is now written by two subagents at the same time, one for the web part and one for the API part, with the plan's endpoint list as their contract; the page shows each one's files, state, time and tokens, and warns when the web calls and the API do not seem to match the plan. A round about the web part only rewrites only that part. Chart value `ai.subagents` (default `true`). Wording reviewed in all three languages: "consolidate" in English, the Japanese README's terms in Japanese, Taiwan wording in Chinese, no fixed punctuation of one language on the page, and every backend error code worded in the page's language. laoban is a community project, not supported by SUSE.
