讓別人照快速上手在自己的環境裝得起來，並加強送給 AI 之前的遮蔽。

laoban 是社群開源專案，不在 SUSE 的支援範圍內。安全相關的注意事項與回報方式見 [SECURITY.md](https://github.com/yansheng133/laoban/blob/main/SECURITY.md)。

## 從 0.1.19 升級

- **`config.clusterId` 改成必填，沒有預設值。** 之前的預設值是作者環境的叢集 ID；沒設的話，「打開應用」會連到不存在的叢集。`values-laoban.yaml` 已經有這個欄位的人不受影響。
- 照 [快速上手](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.md) 新增的「升級」一節：先在 Manage Repositories 對 laoban 按 Refresh，再升級 extension；後端先升 `laoban-crd` 再升 `laoban`。

## 修正

- 不是 Rancher 管理者的人按「確認並部署」後，頁面一直等到逾時（讀不到 Fleet 的狀態）。現在改看應用所在 namespace 的 Deployment 判斷新版本是否已經跑起來。
- 送給 AI 之前，也遮蔽 API key 與 token（Anthropic、GitHub、AWS、GitLab、Google、Slack 等常見格式、JWT、Bearer）與私鑰。`password=`、`密碼：` 後面的值**不會**遮蔽（同樣的字也出現在一般需求與程式碼裡，遮掉會讓 AI 改壞程式），請不要把密碼寫進需求或意見。

## 文件

- 快速上手：
  - 寫明只能用下游叢集（local 叢集不行）。
  - 列出需要的對外連線。
  - 改用本機模型的設定改寫在第 4 節，不再指向作者的實驗室設定。
  - 放應用的 repo 名稱可以自己取，以及 GitRepo 名稱為什麼不能改。
  - 正式使用請用私有 repo（應用的紀錄會寫下需求與使用者 ID）。
  - 新增「升級」一節，疑難排解多三列。
- 新增 SECURITY.md。
- README 說明遮蔽的範圍與限制。
