## 從 0.1.25 升級

照 [快速上手](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.md) 的「升級」一節升級 extension 與兩個 chart。

**用 Rancher Project 角色的環境**：重新套用 `deploy/rancher/roletemplate.yaml`（在 Rancher local 叢集），「laoban user」才有刪除權限。用內建 edit／admin 的人，升級 chart 後就有。

## 新功能：刪除應用

- 應用詳細頁右上的「刪除應用」，以及「應用」清單每一列的「刪除」。只有能刪除的人看得到（有 edit 或「laoban user」角色；viewer 看不到）。
- 按下後頁面先說明會發生什麼，要輸入應用名稱才能刪。
- 刪除是一個 commit，移除 GitHub repo 裡的 `apps/<名稱>/`；Fleet 接著清掉叢集裡這個應用的所有資源，頁面等到清完（最多 3 分鐘）才回到清單並顯示「已刪除」。
- 舊版本仍在 GitHub 的提交紀錄裡，意見收斂的紀錄仍在 `laoban-rounds` 分支，但頁面上無法復原。
- 一輪意見收斂進行中、或正在發布新版本時不能刪，畫面會說明原因。
- API：`DELETE .../apps/<名稱>`，RBAC 動詞是 `apps` 的 `delete`。

---

Apps can now be deleted from the page: "Delete app" on the detail page and "Delete" in each row of the list, for people allowed to delete (edit or the "laoban user" role). Typing the app name confirms; one commit removes `apps/<name>/`, Fleet removes its resources, and the page waits until they are gone. Not while a round runs or a version is being published. If you use the Rancher project roles, apply `deploy/rancher/roletemplate.yaml` again. laoban is a community project, not supported by SUSE.
