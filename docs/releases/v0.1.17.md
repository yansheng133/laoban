第一個可以從 Helm repo 安裝的版本。照 [快速上手](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.md)（[English](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.en.md)、[日本語](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.ja.md)）安裝。

laoban 是社群開源專案，不在 SUSE 的支援範圍內。

## 安裝

- Rancher → Extensions → Manage Repositories → Create，Index URL `https://yansheng133.github.io/laoban`，再安裝 **laoban**。
- 後端：`helm repo add laoban https://yansheng133.github.io/laoban`，安裝 `laoban/laoban-crd` 與 `laoban/laoban`。chart 已填好這個版本的映像檔 digest。

## 新功能

- extension 自己找出後端在哪個叢集、哪個 namespace，任何 Rancher 2.15 都能用（之前寫死在建置裡）。
- Rancher 的側邊選單可以收合，把空間留給工作區。
- 確認過的人看得到「等其他人確認」；發布失敗時，確認過的人也看得到。
- 第一次加草稿時說明其他人看得到（可以關掉）。
- viewer 看不到「新增應用」與編輯按鈕；常見錯誤依介面語言顯示。

## 修正

- `kubectl get rounds` 不再跟 laoban 的 API 撞名：等待中的輪次改名 `waitingrounds`。
- 截止時間選「24 小時後」不會再失敗：超過開始後 24 小時的時間改成剛好 24 小時；錯誤顯示在按鈕旁。
- 過去的輪次依時間由新到舊排列。
- 背景工作（收斂、發布、產生計畫）失敗時，後端 log 寫出原因。
- 時間軸說明以「…」結尾；窄視窗放大時，元件意見框不再被 3D 圖蓋住；日文 Changes 分頁的間距。
- 意見裡的換行照原樣顯示；程式碼分頁的「重新讀取」在有未存修改時先問。
- 收斂中的意見數不算撤回的；一輪滿了以後不再重複顯示訊息；放大時只有一個 Compare with。
