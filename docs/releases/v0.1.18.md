修正 v0.1.17 從 Helm repo 安裝後 extension 載入不了的問題，並依實際安裝的經驗改寫 [快速上手](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.md)（[English](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.en.md)、[日本語](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.ja.md)）。

laoban 是社群開源專案，不在 SUSE 的支援範圍內。

## 從 0.1.17 升級

- 後端：`helm upgrade` `laoban-crd` 與 `laoban` 到 0.1.18。
- extension：Rancher → Extensions → laoban → Update 到 0.1.18。如果之前用 `plugin.versionOverride` 繞過載入問題，升級時把它拿掉。

## 修正

- 從 Helm repo 安裝的 extension 載入失敗（版本號多了一個 v）。發布流程現在會檢查 Helm repo 裡的版本與檔案。
- 收合選單後重新整理，選單又出現。
- 過去的輪次裡，自己的意見顯示使用者 ID 而不是「你」。
- laoban viewer 看得到並能填提意見的區塊（送出才被擋）；應用清單的「Edit」與狀態列的說明。
- 應用清單的「Failed」出現兩次；深色模式下的藍色提示；意見數不算撤回的；英文介面裡應用名稱重複的訊息。
- 側邊選單在每種語言都是「總覽」在前。

## 變更

- 後端的訊息預設改成英文；chart 的 `config.language: zh-Hant` 改回繁體中文。頁面依 Rancher 的語言顯示。
- AI 的計畫依需求的語言寫。
- extension 有自己的圖示；不再標成 Rancher 認證。

## 已知限制

- 每月 token 上限只存在後端記憶體，後端重啟後歸零。請一定要在 Anthropic Console 設花費上限。

---

Fixes the v0.1.17 extension that did not load when installed from the Helm repository, and rewrites the [Quickstart](https://github.com/yansheng133/laoban/blob/main/docs/quickstart.en.md) after a real install. Backend messages are now English by default (`config.language: zh-Hant` for Traditional Chinese). The monthly token cap still resets when the backend restarts: set a spend limit in the Anthropic Console. laoban is a community project, not supported by SUSE.
