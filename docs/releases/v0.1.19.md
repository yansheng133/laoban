後端重啟不再遺失每月 token 用量與還沒確認的計畫。

laoban 是社群開源專案，不在 SUSE 的支援範圍內。

## 從 0.1.18 升級

- **先**升級 `laoban-crd` 到 0.1.19（多了 `Plan` 與 `TokenUsage` 兩個 CRD），再升級 `laoban`。順序反過來也能用，只是 CRD 裝好之前這兩項照舊只存在記憶體；裝好後重啟後端就會開始保存。
- extension：Rancher → Extensions → laoban → Update 到 0.1.19。
- 升級前已經用掉的 token 不會補記；從升級後開始計算。

## 修正

- 每月 token 上限在後端重啟（升級、Pod 重建、節點重開機）後歸零（B21）。用量現在以 UTC 月份存在 `laoban-system` 的 `TokenUsage` 資源：`kubectl -n laoban-system get tokenusages`。
- 產生計畫後、按確認前後端重啟，計畫就不見了。不屬於意見收斂的計畫現在存在 `Plan` 資源，保留 1 小時。重啟時正在套用的計畫不會再套用一次，請重新產生。

## 已知限制

- token 上限只是 laoban 自己的計數，不是 Anthropic 的帳單。請一定要在 Anthropic Console 設花費上限。
